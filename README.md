The Tic-Tac-Toe Game is a simple and interactive project implemented using front-end technologies like HTML, CSS, and JavaScript. This game is a two-player turn-based strategy game, where the players alternately place their marks (X or O) on a 3x3 grid. The objective of the game is to form a horizontal, vertical, or diagonal line of three marks before the opponent does.

* Key Features:

Dynamic Gameplay: The game automatically highlights the winner or declares a draw if all cells are filled.
Reset Option: Players can reset the game board to play again.
User-Friendly Interface: The design is clean and intuitive for users of all ages.
Interactive Logic: JavaScript powers the core game logic, ensuring smooth transitions and real-time updates.
This project is ideal for beginners looking to understand DOM manipulation, event handling, and the basics of game logic in JavaScript. It is a fun and educational way to learn front-end development!
